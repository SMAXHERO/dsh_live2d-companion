### Sutera-Diffusus/dsh-whale-musume（stars 未取到；JavaScript 为主 + Python 资源生成脚本；DSH 的“鲸鱼娘”桌宠主题：纯前端注入 + 只读静态资源路由，无构建、无 Live2D，90+ 张 webp 立绘 + 620 条台词 + 45 成就 + 3 个小游戏 + 跨端存档，npm 包 v2.5.0）

- 安装/运行：`dsh plugin --profile web add dsh-whale-musume`（桌面端 Electron 壳与旧版 Web profile 通用，双端支持）；`assets/` 即运行产物，零构建零依赖，`lib/index.js` 注册只读路由 `/api/dsh-whale-musume/assets?f=`，`lib/client.js` 启动时取 css + `whale-moe-core.js` + `dsh-whale-moe.js` 三个文件注入宿主页面。

- 设定/人设：**没有 LLM、没有 system prompt（未见）**，人设由硬编码台词库承载：`assets/whale-moe-core.js` 的 `DIALOGUE`（行 1286–2140）11 个分组共 620 条（daily 100 / work 100 / interact 115 / keyword 109 / meme 30 / context 28 / weather 36 / greet 30 / bond 25 / balance 29 / proactive 18）。台词里“主人”“鲸鱼娘”是占位词，`applyNames(line, title, selfName)` 运行期替换成用户设置的称呼与自称（`localStorage` 键 `whale-moe:title` / `whale-moe:selfName`，各 ≤20 字并剥离控制字符，默认「主人」「鲸鱼娘」）；称呼也是 45 成就之一（`bond-badge` 来自 Lv5 称号「鲸汐守护者」）。语气规范写在 `docs/superpowers/specs/2026-08-15-meme-dialogue-weather-design.md`：可爱为主、只玩安全梗、明确不碰政治/歧视/争议梗；开场白不是 prompt，而是按时段的问候语库 `greet`（6 段：23–6 night、<9 morning、<12 forenoon、<14 noon、<18 afternoon、else evening，边界 5:59/6:00 进单测）。

- 形象/Live2D：**无 Live2D、无 Cubism、无 pixi**（`package.json` 无渲染库依赖）。素材是 `assets/generated/` 下 ~90 张 webp，命名 `dsh-whale-state-<pose>.webp`；渲染为两层 DOM `<img>` 的 “motion-hide swap”（`assets/dsh-whale-moe.js` `setPose`，行 186-）：旧姿势下蹲压扁、新姿势带过冲弹回，不做透明度淡入，只保留一层可见（防穿帮）。表情=直接换图：`showMood(pose, duration, animate)` 临时覆盖立绘 1.8–7s（`achievement` / `levelup` / `game-win` / `game-happy` / `game-lose` / `balance-low` / `eat` / `angry` …）。口型/眨眼：未见（没有音频驱动）。

- 动作逻辑：DOM 刮信号 → 纯函数状态机，两层分离。表现层 `assets/dsh-whale-moe.js` 的 `SIGNAL_BANKS`（行 52–59）把宿主 UI 选择器映射成 thinking / tool / error / success / code / chat 六类（如 `[data-tool][data-state="running"]`、`[data-chat-running]`）；`collectSignals()`（行 2027–2081）消抖 300ms 后输出 `{view,thinking,tool,error,successAt,curiousAt,denseCode}`；**信号消失后按视图保持**（主页 4s / 工作台 8s，避免工具面板任务间短暂空白导致姿势抽搐）；可见 `pre`/终端节点 ≥3 时 `dense=true` 切 mini 视图。核心 `assets/whale-moe-core.js` 的 `computeState(prev, signals, now, rng)`（行 210–247）按 “error > tool > thinking > success(2s 窗口) > curious(6s) > waiting > afk(180s)/idle” 出 `{state, pose, line, speak, mode}`，`POSES` 表 27 项（`idle:"idle-cute"`、`tool:"running"`、`workSlack:"work-slack"`、`workPat`、`pick-up`…）。空闲行为：每 18–28s 从 14 张 `IDLE_ACTION_POOL` 随机做微动作、35–60s 一次小动作；点击用 `hitZone(nx,ny)` 分头/肚皮/尾巴三区，各配专属立绘 + 台词 + emoji 粒子；忙态点她随机 `work-pat` / `work-ram`。**“跟随 agent 工具调用”的映射确实存在**：`TOOL_POSES`（`assets/dsh-whale-moe.js` 行 2302–2352）8 条 `{pose, words}` 规则，取最后一个可见工具卡的 `textContent` 小写后 indexOf 匹配 deploy / test / debug / search / write / bash / review / plan → `work-deploy` / `work-review` / `work-debug` / `work-idea` / `work-meeting` / `work-slack-phone`；识别不出返回空串回落通用 running（注释强调“绝不乱切”），`whale-moe:toolPose` 开关。

- 对话逻辑：**不接大模型**。事件驱动选台词：`say(bank, event)`（行 1712）按 (bank,event) 计数器轮询 `pickDialogue`，`pickDialogueAvoidRecent` 去重最近 N 条；心情低/高时 15% 概率换成 `bond` 的 low-mood/high-mood 台词。“上下文”靠当轮任务文本：`classifyTask(text)`（core 行 2327–2334）把任务分成 deploy/bug/data/code/write/research/general 七类，用来挑 `context` 组贴题台词；关键词走 `matchKeyword`（30 组词→meme id），纯本地 indexOf，注释明确“绝不上传”。流式 / JSON 结构化输出 / 失败兜底：未见（无 LLM 调用）。节奏约束很硬：工作态台词两档冷却窗口 `workSpeechAllowed` —— 话痨 15–40s、安静 90–240s，窗口内只说一句（presenter 行 2999–3032，切档立即清窗口）；空闲闲聊 5–8 分钟一次；问候间隔 3h；`BUSY_STATES={thinking,tool,success,failure}` 忙时一律不闲聊、不切小剧场；23:00–5:59 静默。

- 对话长度：**靠写作规范而不是代码截断**。620 条台词实测中位 22 字、p95 29 字、最长 33 字，全部单行无换行、句末恰好 1 个 emoji（例：“冲 DDL 啦！鲸鱼娘把时钟藏起来了，看不见就不紧张，聪明吧🕰️”）。代码侧只做频率约束（`SPEECH_GAP_MS=6000` 内最多一句、状态不变不重播、avoidRecent），长度只进验收测试（词库总量 ≥480、单行等）——这一条对“不许换行/长句”的本地需求最有参考价值。

- 表情包/贴纸：素材是 **18 张 `meme-*` webp 立绘**（doge/doubt/heart/kyun/music/no/ojisan/omg/peace/sike/smile-pain/smug/wakuwaku/worship/yes/broke/cry/shock），不是 emoji 也不是渲染图。触发方式是本地关键词：`KEYWORDS`（core 行 1241–1272）30 组词（谢谢/好累/饿了/晚安/加油/求夸/抱抱/可爱/早上好/摸鱼/slack/ddl/蛋糕/发疯/立 flag/bug/kyun/omg/doge/sike/崇拜/peace/怀疑/期待/苦笑/大叔/deploy/meeting/review）命中即现场变身对应 meme 立绘并说 meme 组台词；另有 emoji 粒子 `burst("🍰"/"💢"/"✨"/"🏅")`。**没有“模型可调用的发贴纸工具”（未见）**，全部由 UI 事件与用户文本关键词触发。

- 其他亮点：
  - **45 项成就**（core 行 651–697）：每项 `{id, icon(emoji), name, desc}` 的静态 `Object.freeze` 数组，覆盖互动（first-pat / ten-pats / hundred-pats / first-feed / first-triple / thanks）、等级（lv5 / lv10）、签到（signin3 / signin7）、时段（night-owl / comeback / night-work）、陪伴（day1/7/30/100/365）、DSH 用量（first-tool / tools-10/50/100 / first-code / code-20 / first-success / success-10 / first-failure / fail-10 / messages-100/500 / keyword-master / balance-low）、游戏（game-first / game-win / game-combo10 / game-highscore / memory-first / memory-clear / memory-perfect / memory-combo6）、任务（quest-first / quest-all / week-signin7）、羁绊（bond-action / bond-badge）。**存储 = `growth.achievements` 的字符串 id 数组**（非对象、非位图）；解锁判定拆成 5 个纯函数：`computeGrowth`（704 判互动类）/ `evaluateAchievements`（764 判等级与签到）/ `evaluateGameAchievements`（366）/ `evaluateMemoryAchievements`（627）/ `evaluateQuestAchievements`（1230），presenter 另有 `USAGE_TIERS`（行 1667–1681）13 档计数阈值（tools/code/successes/failures/messages/keywords）；解锁统一走 `announceUnlocks(ids)`（行 849）：换 `achievement` 立绘 3.5s + 🏅 粒子 + 气泡“成就达成：xxx！” + 写成长日记 + aria-live 播报；设置面板 `MascotAchievementWall` 是 45 格成就墙（未解锁 opacity 0.38，头部 “n / 45”）。
  - **3 个小游戏全是 DOM-free 纯函数状态机**（可在 `node --test` 里跑，见 `test/whale-moe-game.test.js` 一类）：① 戳泡泡 `GAME`：4×4 网格、30s、泡泡寿命 1600ms、星/炸弹概率 15%/10%、连击窗口 1200ms、win 300 分 / draw 150 分，`gameNewState/gameTick/gamePop/gameResult/gameReward`；② 接点心 `CATCH`：30s、篮子宽 0.18 屏、每秒下落 0.16–0.42 屏高、蛋糕 75% / 星 15% / 炸弹 10%；③ 鲸鱼翻翻乐 `MEMORY`：8 对 4×4、60s、翻回 900ms、连击上限 4、按秒加时间奖励，**16 张配对脸直接复用真实立绘** `MEMORY_FACES`（daily-coffee/daily-eat/…/meme-kyun/wink，注释写明表现层可传自己的候选池，核心只洗牌取前 8）。每天最多 3 局给养成奖励（`gameRewardAllowed`，行 360），防刷。
  - **跨端存档迁移**（core 行 776–1102）：`PORTABLE={SCHEMA:"dsh-whale-musume/save", VERSION:1, MAX_TEXT:200000, MAX_JSON:65536}`，16 个白名单字段（mood/affinity/satiety/lastSignin/signinStreak/achievements/companionSince/level/quests/weekSignin/badge/gameStats/usageStats/journal/title/selfName，其中 12 个进迁移码 `CORE_KEYS`）；`portableSanitizeData` 逐字段校验并夹紧（mood 0–100、affinity 0–10000、level 1–999、lastSignin 正则、achievements 按已知 id 过滤去重、title/selfName ≤20 字、journal ≤80 条）；**设备相关字段明确不迁移**（窗口坐标 `floatX/floatY`、天气经纬度、一次性标记）；迁移码格式 `WM1-<8 位 FNV 校验>-<base64url>`，手写 base64/UTF-8 不依赖 Buffer/btoa（双端环境都能跑）；导入前先弹 `portableSummary`（Lv / 好感 / 成就数 / 陪伴天数）确认，坏码不动现有存档，错误文案是中文（“这不是鲸鱼娘的存档文件”）。
  - 每日任务 6 条池、3 槽每日刷新（优先与昨天不同）、周签到 7 格（3/7 奖励里程碑）、羁绊 Lv3 动作 / Lv5 称号 / Lv7 彩蛋；成长数值 `mood/affinity/satiety/level=floor(affinity/500)+1`，`satiety` 每分钟衰减 0.15。
  - 持久化：`localStorage` 前缀 `whale-moe:`，一个关注点一个 key（growth / gameStats / usageStats / quests / weekSignin / journal / badge / title…），读取全 try/catch 兜底；成长日记 `journal` 最多 80 条，同日同 kind 同 text 去重。
  - 语音：不自研 TTS，presenter 行 679 / 725 向 root 派发 `CustomEvent("dsh-whale-musume:interaction-line", {detail:{text}})`，由宿主安装的 `dsh-xiaomi-tts` 插件决定是否朗读（默认关）；ASR 未见。
  - 性能与工程：首屏只预载 11 张立绘（`POSE_PRELOAD_CORE`），其余 90+ 张用 `requestIdleCallback` + 每 120ms 一张空闲预取；游戏 tick 250ms/100ms；适配 `prefers-reduced-motion` / forced-colors；核心 `whale-moe-core.js`（2440 行，纯逻辑）与表现层 `dsh-whale-moe.js`（3672 行）严格分离，`test/` 28 个 node 单测 + `tools/dom-stub`（45KB 假 DOM）支撑 presenter 测试。

- ★可直接搬给本地项目（D:\AICode\live2d-companion）的 4 条：
  1. **成就三件套可直接照抄**：`assets/whale-moe-core.js:651-697` 的 `{id, icon, name, desc}` 静态表 + `growth.achievements` 字符串 id 数组 + 按域拆开的 `evaluateXxx(have, stats)` 纯函数（366 / 627 / 764 / 1230）。本地项目现在无记忆/无成就，加一张表 + 一个数组 + 若干判定函数即可，接现有情绪状态机的 pat/feed/success 事件，零数据库。
  2. **小游戏纯函数化 + 每日奖励上限**（`whale-moe-core.js:300-375`、`gameRewardAllowed:360`）：状态机不碰 DOM，UI 只做渲染，本地 Canvas 2D 更容易接；“每天 3 局才给养成数值”是比成就更轻的留存钩子。
  3. **“按工具类型切姿态”映射**（`assets/dsh-whale-moe.js:2302-2352`）：8 条 `{pose, words[]}` + 取最后一个工具卡文本 + indexOf + 识别失败回落，工程量极小，却让桌宠“看起来在跟你一起干活”；本地项目已有工具调用事件，加一张 `toolPose` 表就能用。
  4. **meme 关键词反应 + 台词长度规范**（`whale-moe-core.js:1241-1272` 关键词表、620 条台词实测 ≤33 字单行、`dsh-whale-moe.js:2999-3032` 工作态冷却窗口）：本地项目无表情包系统，最小可行版是“关键词 → 情绪动作/贴图 + emoji 粒子”，再配“忙时闭嘴 + 话痨/安静两档节流”；对话长度靠提示词规范 + 验收测试而不是代码截断。
